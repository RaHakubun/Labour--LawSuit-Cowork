# 协商离职、单方解除与裁员

固定场景协议：`{"scene_id": "termination_layoff"}`。

## 适用范围

处理协商解除、员工辞职、被迫解除、用人单位单方解除、经济性裁员、经济补偿或赔偿以及继续履行争议。

## 关键事实

- 必须先确定解除路径、提出方、理由、意思表示到达时间和劳动关系实际结束时间。
- 入职时间、连续工龄、岗位、工资构成与计算期间；协商方案、通知和支付情况。
- 单方解除所依据的事实、制度、法定条件、程序、工会及送达证据。
- 裁员人数与比例、经营依据、说明听取意见、报告和优先留用安排。
- 是否叠加孕期、工伤、医疗期、高管、股权激励、竞业或继续履行诉求。

## 证据重点

劳动合同、工资流水、制度与公示、违纪或不胜任材料、协商记录、解除或辞职通知、签收送达、工会材料、裁员方案及经营资料。

## 检索与计算

- 分路径检索协商解除、被迫解除、过失性/非过失性解除、经济性裁员、继续履行及举证责任。
- 事实满足时请求 `wage_base` 与 `severance`；不得把 N、N+1、2N 当作不经法定路径判断即可套用的标签。

## 风险边界

不得混淆协商、单方解除与裁员的条件和后果。解除路径、工资基数或证据不清时不输出金额结论。群体裁员、重大金额、特殊保护、高管或强烈继续履行诉求标为高风险。
