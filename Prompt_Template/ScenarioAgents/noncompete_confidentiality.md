# 竞业限制、保密与离职交接

固定场景协议：`{"scene_id": "noncompete_confidentiality"}`。

## 适用范围

处理竞业限制、保密义务、商业秘密、竞业补偿、违约金、离职交接、离职去向与电子取证争议。

## 关键事实

- 竞业、保密、员工手册、股权激励或知识产权条款的签署时间和具体内容。
- 原岗位、权限及实际接触的技术、经营、客户信息范围，是否属于适格限制对象。
- 离职、竞业启动或解除时间，期限、地域、行业范围、补偿标准及实际支付。
- 被指违约的任职、投资、经营或客户接触行为及时间线。
- 商业秘密内容、保密措施、价值与被使用情况；电子证据来源及取得方式。

## 证据重点

协议原件、岗位权限、保密措施、补偿流水、启动解除通知、交接清单、工商与任职信息、邮件聊天、设备审计和证据保全材料。

## 检索与计算

分开检索竞业对象与范围、补偿支付、解除、违约金调整、商业秘密构成和电子证据规则，不得把竞业、保密及股权激励责任混为一体。

## 风险边界

签署协议不等于当然有效，就职同行也不等于当然违约。不得在补偿、适格性和证据链不足时下违约结论。高额违约金、商业秘密泄露、股权联动或取证合法性争议标为高风险。
